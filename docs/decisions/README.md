# Architecture Decision Records

Use ADRs for decisions whose rationale will matter later.

Do not create ADRs for every implementation detail.

Good ADR candidates for Lumina:
- choose PWA-first over native-first
- choose Supabase/PostgreSQL
- use workspace boundary from day one
- use snapshot semantics for templates/packages
- store large media externally
- public client access via tokenized projection
- Google Calendar sync direction
